Tecnologías principales
Node.js  
Plataforma de ejecución de JavaScript en el servidor.
→ Permite crear tu API REST.

Express.js  
Framework minimalista para Node.js.
→ Maneja las rutas (GET, POST, PUT, DELETE) y la lógica de tu servidor.

PostgreSQL 18  
Base de datos relacional.
→ Almacena tu tabla invent con los productos y precios.

pg (node-postgres)  
Cliente oficial de PostgreSQL para Node.js.
→ Se encarga de la conexión y ejecución de queries.

dotenv  
Librería para manejar variables de entorno desde .env.
→ Mantiene seguras tus credenciales y configuración.
